The Tech Stack Film Crew

A modern web application is like a film crew, where different specialists collaborate to produce a single seamless experience. Let's meet the characters in the UGSkill project:

🎬

The Director (Frontend)

React 19 & Vite: Decides exactly what the student sees, draws the video player, captures button clicks, and orchestrates client interactions.

💼

The Producer (Backend)

Express.js & Node: Coordinates everything behind the scenes, checks permissions, handles API routing, and runs the business checks.

⚡

The Runner (Cache)

Redis: A fast runner that keeps temporary statuses (like active exam heartbeats or session tokens) ready in seconds.

The Dual Database Archivists

Instead of relying on a single filing system, UGSkill uses a dual database setup to balance speed, structure, and reliability:

The SQL Ledger (PostgreSQL & Supabase)

Stores transactional, structured data in tables with rigid relationships. This is where student records, course catalog data, placement drives, and verified exam scores live.

Why? Because grades and placements require absolute relational integrity (no orphan records).

The NoSQL Folder (MongoDB)

Stores flexible, unstructured JSON-like documents. This is where polymorphic quiz questions, mock interview responses, and raw webcam proctoring activity events are filed.

Why? Because quizzes can have diverse formats, and proctoring activity streams require high-write speed without rigid schema checks.

💡
Steering AI on Databases

If you instruct an AI assistant to "add a user metadata field like a bio," explain whether it belongs to the relational profile (Postgres) or the flexible, polymorphic metadata object (MongoDB).
