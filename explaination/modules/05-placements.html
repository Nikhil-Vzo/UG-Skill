The Gatekeeper Metaphor

Before a student is allowed to enter a restricted room on campus (the Placement Interview rooms), a Gatekeeper checks their pass:

📈

The Pass Check (CGPA Cutoff)

Every company sets a custom academic threshold. The gatekeeper verifies the student meets this requirement before booking slots.

📄

Portfolio Check (Resume Validation)

No resume, no entry. The system ensures a valid resume URL is linked to the student profile to prevent empty profiles from reaching HR.

🔑

Official Stamp (Postgres Registration)

A transactional record is created in PostgreSQL with status set to 'registered', serving as the official ticket to proceed. Deleting a drive triggers a Cascade Delete, wiping out registrations in PostgreSQL to avoid orphan records.

💡
Steering your AI Assistant

When requesting changes to placement eligibility rules (e.g. adding branch/major cutoffs), direct the AI specifically: "Modify the eligibility checks in the placement service to compare student branch with allowed branches from the drive configuration."

Behind the Scenes: The Gatekeeper Code

Let's trace the backend code checks in placement.service.ts that run when a student clicks register:

CODE 
export const registerForDrive = async (studentId, data) => {
  const drive = await placementRepo.getDriveById(data.driveId);
  if (!drive) {
    throw new NotFoundError('Drive not found');
  }
  const existing = await placementRepo.getRegistration(studentId, data.driveId);
  if (existing) {
    throw new AppError('Student already registered', 409);
  }
  const user = await userRepo.findById(studentId);
  if (!user) {
    throw new NotFoundError('User not found');
  }
  if (drive.eligibility && drive.eligibility.cgpaCutoff !== undefined) {
    const cutoff = drive.eligibility.cgpaCutoff;
    const userCgpa = user.cgpa ? Number(user.cgpa) : 0;
    if (userCgpa < cutoff) {
      throw new AppError('CGPA below required cutoff', 422);
    }
  }
  if (!user.resumeUrl) {
    throw new AppError('Resume is required', 422);
  }
  const registration = await placementRepo.insertRegistrationPg({
    studentId,
    driveId: data.driveId,
    status: 'registered'
  });
  return registration;
};
