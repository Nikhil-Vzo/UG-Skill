# 📋 Feature Specifications

Detailed, interactive HTML documents describing every feature across UGSkill's three main modules.

---

## Files

| File | Module | Feature Count |
|------|--------|---------------|
| [lms-features.html](./lms-features.html) | Module 1 — LMS | Courses, quizzes, roadmaps, streaks, certificates, AI tutor |
| [placement-features.html](./placement-features.html) | Module 2 — Placement | Mock interviews, GD, company drives, readiness scoring, peer groups |
| [exam-features.html](./exam-features.html) | Module 3 — Exam | Question pools, proctoring, scoring, rankings, section navigation |

---

## How to Use

1. **Open** — Double-click the `.html` file or drag into browser
2. **Browse** — Scroll through feature cards organized by sub-module
3. **Explore** — Click cards for detailed breakdowns

---

## Purpose

These specs define **what** each module does before any code is written. They serve as:

- 📐 **Design reference** for UI/UX decisions
- ✅ **Acceptance criteria** for feature completion
- 🧪 **Test case source** for QA validation
- 📖 **Onboarding docs** for new team members
